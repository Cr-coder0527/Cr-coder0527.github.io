本文记录了我从零开始搭建本博客的全过程：使用 Hexo 生成静态网页，使用 hexo-theme-matery 主题，并免费部署到 GitHub Pages。全程零服务器成本，跟着步骤做，你也可以拥有一个自己的博客。

适合谁看： 想拥有个人博客、但不了解前端工程化的初学者。只需要会打开终端、复制命令即可，不需要数据库和云服务器。

一、整体思路

Hexo 是一个基于 Node.js 的静态博客框架：我们用 Markdown 写文章，它负责把文章套进主题模板，生成一堆 HTML/CSS/JS 文件；然后把这些文件推送到 GitHub 仓库，GitHub Pages 会自动把它们发布成网站。

八、常用命令速查

命令缩写作用

hexo serverhexo s本地预览
hexo generatehexo g生成静态文件
hexo deployhexo d部署到 GitHub
hexo cleanhexo cl清理缓存（改动异常时先清理）

九、可以继续完善的方向

一个基础博客上线后，还可以按下面的清单继续打磨：

  • 更换主题并配置头像、导航和色彩
  • 开启本地搜索（基于 search.xml）
  • 接入评论系统（Gitalk / Waline / Twikoo）
  • 添加不蒜子访问量统计与文章阅读次数
  • 添加音乐播放器和文章目录（TOC）
  • 制作原创页面（比如我放在导航里的俄罗斯方块、贪吃蛇小游戏）
  • 绑定自定义域名（在 source 目录放 CNAME 文件并配置 DNS）
  • 坚持更新，让博客真正成为记录成长的地方

十、写在最后

搭建博客本身只是几个命令，但持续地写作和记录才是博客真正的价值。技术问题基本都能通过搜索和官方文档解决，不必害怕报错——我在搭建过程中也踩过依赖版本、部署分支、中文链接等一堆坑，耐心看报错信息，逐个解决就好。

愿我们都能在自己的一方小天地里，写下去。
