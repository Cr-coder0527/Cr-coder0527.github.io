这篇文章是我在搭建博客过程中整理的 Markdown 学习笔记。Markdown 是一种轻量级标记语言，用简单的符号就能完成排版，非常适合写博客、记笔记和写技术文档。本文涵盖了日常写作最常用的全部语法，也可以当作速查手册使用。

阅读提示： 本文使用本博客主题（hexo-theme-matery）渲染，文中展示的大部分语法都是 GitHub Flavored Markdown（GFM） 标准语法，在 GitHub、Typora、语雀等平台同样通用。

一、标题

使用 # 号表示标题，# 的数量对应标题级别，一共支持六级：

写博客时建议最多用到三级标题：一级标题是文章名，正文从二级标题开始分节，层级太深反而不利于阅读。本文右侧（移动端在顶部按钮）的目录就是根据二、三级标题自动生成的。

二、字体样式

Markdown 使用成对的符号修饰文字：

语法 效果 说明
**粗体** 粗体 双星号包裹
*斜体* 斜体 单星号包裹
***粗斜体*** 粗斜体 三星号包裹
~~删除线~~ 删除线 双波浪线包裹
`行内代码` 行内代码 反引号包裹

此外，Markdown 允许直接写 HTML 标签，可以实现更丰富的样式，比如 Ctrl + C 表示快捷键，高亮文字 表示重点。

九、结语

Markdown 的核心语法其实一页纸就能写完，真正的提升来自于持续地使用。写得多了，这些符号会变成肌肉记忆，你只需要专注于内容本身。

写作建议：不要为了排版而写作。先把想法写下来，再用 Markdown 梳理结构。
